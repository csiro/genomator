Evaluate Privacy Metric

To evaluate the privacy metric of the generated data, you need the following information:
  • Input VCF file - The original VCF file containing your genomic data.
  • Generated VCF file - The synthetic VCF file generated from the original data.
  • Number of trials (Optional) - The number of times the evaluation is repeated to ensure accuracy.
  • Degree of privacy metric (Optional) - Number of SNPs involved in each private combination.
