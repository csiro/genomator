Evaluate Synthetic Data

Upload the original VCF file and the synthetic VCF file generated for it on the Generate tab, then choose a metric to evaluate.
  • Accuracy Metric - Measures how closely the synthetic data reproduces the statistical distribution of the original data, using a sliced Wasserstein distance.
  • Privacy Metric - Measures how much private information from the original data could be inferred from the synthetic data, using unique-combination reproduction rates.
  • In-Depth Privacy Metric - A more thorough membership-leakage check, done by comparing Genomator against other synthetic data generation tools rather than scoring it in isolation. This comparison needs more compute than a browser tab can offer, so it runs as a downloadable local script instead of on this page — see that tab for instructions.
The Accuracy and Privacy metrics above execute entirely on your own computer in your web browser; data is never transmitted outside your device. The In-Depth Privacy Metric also runs only on your own computer, as a local script rather than in the browser.

The in-depth privacy metric is a membership-inference-style check: it splits a real cohort in half, regenerates synthetic data from each half, and asks whether a real individual's own half sits detectably closer than the other half's. The original Genomator paper used exactly this kind of check to show Genomator's privacy advantage — by comparing it against other synthetic data generation tools (a Markov-chain baseline, and deep-learning baselines such as CRBM/WGAN/RBM), not by reporting Genomator's score in isolation. A score on its own, without that comparison, is easy to misread.

Genomator's SAT-based approach is lightweight enough to run in a browser tab, which is why the rest of this page can run entirely client-side. The baseline tools it needs to be compared against are not — the deep-learning baselines in particular need meaningfully more compute and memory than a browser tab can offer. So this comparison runs as a local script instead of in the browser.

Run it locally:
  1. Get the scripts from the Genomator GitHub repository, under genomator-web/membership-inference-attack-metric/.
  2. Follow the setup steps in that folder's README.md (create a virtual environment, then pip install -r requirements.txt).
  3. Run the comparison against your real cohort: 
    python3 run_comparative_privacy_experiment.py --input your_real_data.vcf --tools genomator,markov
  4. Optionally add the deep-learning baselines (crbm, wgan, rbm) to --tools once you've installed PyTorch as described in the README — they're slower and need more memory, so they're left out by default.

The script prints both the mean and median own-half vs. other-half distance for every tool you run, side by side, so you can judge Genomator's relative standing yourself — the same comparison the original paper made.
