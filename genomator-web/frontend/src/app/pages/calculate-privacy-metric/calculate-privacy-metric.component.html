Evaluate Synthetic Data

Upload the original VCF file and the synthetic VCF file generated for it on the Generate tab, then choose a metric to evaluate.
  • Accuracy Metric - Measures how closely the synthetic data reproduces the statistical distribution of the original data, using a sliced Wasserstein distance.
  • Privacy Metric - Measures how much private information from the original data could be inferred from the synthetic data, using unique-combination reproduction rates.
  • In-Depth Privacy Metric - A more thorough membership-leakage check: splits your input cohort in half, generates synthetic data from each half separately, and checks whether real individuals sit suspiciously closer to the synthetic data generated from their own half than from the other half. Only needs your original input VCF — it re-runs Genomator's generation twice internally, so it takes noticeably longer than the other two methods.
All metric evaluation executes entirely on your own computer in your web browser. Data is never transmitted outside your device.
